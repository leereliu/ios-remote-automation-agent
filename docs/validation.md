# 验证记录

## 原型真机验收

2026-10-18，在 2018 款 11 英寸 iPad Pro、iPadOS 18.6.2、1194×834 点横屏上完成。

- Mac 与 iPad USB 已断开，Mac 使用手机热点，iPad 使用家庭 Wi-Fi；组网客户端关闭。
- 常驻主机 systemd Agent 独立领取新目标，通过真实 Codex CLI 与 MCP 执行。
- 样例：进入哔哩哔哩，打开指定 13:54 视频，先移动至 00:32，再调整至 05:00，保持暂停，最后隐藏控件。
- 全程 142.41 秒，8 次 MCP 调用，对应 10 条底层 operation；部分工具包含辅助截图。
- 精确定位那条本地 sequence 从输入开始至截图约 2470.1ms。
- 验收标准为播放器显示 05:00 与暂停三角；未认证解码帧时间戳。

原始截图、任务 ID、设备标识与日志保存在私有部署工作区，本仓库不附带这些个人数据。本次证明拔线与跨网络执行，Mac 完全关机、跨夜、锁屏、重启与长断网恢复尚未完成验收。

## 自动校验

`npm test` 包含 8 项现有契约测试：HTTPS 与健康检查、静态页面不含钥匙、角色拒绝、操作白名单、sequence 全量校验、截断响应只重试原只读请求、提交响应丢失按原 UUID 恢复、权限拒绝不重试。

这些测试没有覆盖真实 D1 原子领取、并发和全部原生 XCTest 路径；成功测试无法代替真机与长稳实验。
