# 验证记录

## 原型真机验收

2026-10-18，在 2018 款 11 英寸 iPad Pro、iPadOS 18.6.2、1194×834 点横屏上完成。

- Mac 与 iPad USB 已断开，Mac 使用手机热点，iPad 使用家庭 Wi-Fi；组网客户端关闭。
- 常驻主机 systemd Agent 独立领取新目标，通过真实 Codex CLI 与 MCP 执行。
- 样例：进入哔哩哔哩，打开指定 13:54 视频，先移动至 00:32，再调整至 05:00，保持暂停，最后隐藏控件。
- 全程 142.41 秒，8 次 MCP 调用，对应 10 条底层 operation；部分工具包含辅助截图。
- 精确定位那条本地 sequence 从输入开始至截图约 2470.1ms。
- 验收标准为播放器显示 05:00 与暂停三角；未认证解码帧时间戳。

原始截图、任务 ID、设备标识与日志保存在私有部署工作区，本仓库不附带这些个人数据。本次证明拔线与跨网络执行，Mac 完全关机、跨夜、锁屏、重启与长断网恢复尚未完成验收。

## 自动校验

`npm test` 包含 15 项测试，覆盖 HTTPS 与健康检查、静态页面不含钥匙、角色拒绝、操作白名单、sequence 全量校验、截断响应只重试原只读请求、提交响应丢失按原 UUID 恢复、权限拒绝不重试，以及 Bot 预算和跨进程锁。新增 SQLite 实际 SQL 校验清理索引、每批 100 条边界、保留时间、心跳限频与领取顺序；虚拟时钟覆盖长轮询任务到达、窗口边界与取消；C 编译测试覆盖设备端待机策略与错误退避。

这些测试没有覆盖真实 D1 原子领取、并发和全部原生 XCTest 路径；成功测试无法代替真机与长稳实验。

## 待机与索引优化验收

2026-10-18，在同一 iPad 上签名安装 `ipad-https-3`。部署沿用既有数据库和运行凭据，新增清理索引与待领取任务的过期时间索引。线上清理候选查询读取由 203 行降至 1 行；领取查询计划使用 `jobs_pending_expiry` 的有效期范围检索。自动测试 15 项、Python 语法检查、签名构建和签名校验通过。

用户确认拔掉 USB 后，三条状态查询与一条截图均完成，排队领取耗时依次为 1786、3601、857、3495ms；截图从创建至完成为 3937ms。设备日志确认空闲保持时间从 5 秒升至 10 秒、20 秒，稳态领取请求间隔约 20.36–20.59 秒；完成任务后恢复 5 秒窗口，连续空闲后再次升至 20 秒。

补上待领取索引后再次验收：120 秒稳态窗口内，设备日志记录 6 次领取请求，均使用 20000ms 保持窗口，响应均为 HTTP 200。随后新建的状态与截图任务分别在 3440ms、4362ms 内领取，截图全程 4749ms。合计 6 条真机操作全部完成。设备侧待机请求按该小窗口折算约 4320 次/天，相比此前 10 分钟窗口折算的 15984 次/天减少约 73%；这属于短窗口外推，未完成全天验证。

同日较早的 120 秒稳定窗口，Cloudflare 统计为 6 次 Worker 请求、2 行 D1 心跳写入、0 个 Worker 错误、CPU P99 6.638ms。心跳策略在随后领取索引更新中保持一致，按每分钟最多写入一次估算，每天最多 1440 行，较旧测量值 14832 行/天减少约 90%。Cloudflare 小窗口数据存在统计延迟，最终版本的请求频率同时以设备日志核对。D1 总读写还包含任务和索引维护，不能将这些比例套用于全部用量。

初次启动期间观察到一次 62.65 秒的调度间隔，发生在一次成功的空领取响应与下一次领取之间，随后自行恢复。当时没有排队任务，原因尚未确认；本次未将这段间隔计入稳态节省比例，也未认证启动、拔线或 iPadOS 生命周期切换的最坏响应时间。跨夜运行与物理关闭 Mac 仍保留在原验收清单中。
